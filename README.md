**Home Network Topology Chart**

Home lab documentation covering physical and virtual topology, device inventory, standardized naming, and network relationships.



**Objectives**

- Document the physical and virtual structure of the home lab environment in a clear and easy-to-reference topology.
- Show how network infrastructure, physical endpoints, and hosted virtual machines relate to one another.
- Create a device inventory that identifies each system by device name, platform, connection type, and operational role.
- Demonstrate how standardized infrastructure documentation can support troubleshooting, onboarding, knowledge transfer, and future network changes.

**Home Lab Topology**

- Documents the physical and virtual structure of the home lab environment.
- Shows the relationship between the Spectrum modem, Spectrum router, wireless endpoints, Linux systems, and hosted Windows virtual machines.
- Provides a visual reference that can support troubleshooting, onboarding, configuration changes, and environment awareness.

![Home Lab Topology](images/01%20Home%20Lab%20Topology.png)


**Device Inventory**

- Identifies the devices in the home lab by device name, device type, operating system or platform, connection method, and operational role.
- Distinguishes physical systems from hosted virtual machines and documents which host system each virtual machine runs on.
- Provides a quick-reference inventory that supports asset awareness, troubleshooting, documentation, and future environment changes.
